# Luna — Personal Website

A custom, responsive personal introduction and developer portfolio for [tylermckeown.me](https://tylermckeown.me).

## Features
- Editorial dark visual design with a restrained violet accent.
- Responsive layout for desktop, tablet, and mobile.
- Motion details, scroll reveals, and a subtle pointer glow.
- About, selected work, development experience, and GitHub activity sections.
- Live public contribution chart for [LunaHasCode](https://github.com/LunaHasCode).
- Featured CollegeShit project linking to [cs.tylermckeown.me](https://cs.tylermckeown.me).
- Reduced-motion support and semantic navigation.

## Run locally
No build step or dependencies are required. Open `index.html` in a browser or serve the directory with any static HTTP server.

## Deploy
The repository is static-site friendly and can be deployed using GitHub Pages, Cloudflare Pages, or any static host. Set the custom domain to `tylermckeown.me` in the hosting provider and configure DNS there.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual system and animations
- `script.js` — lightweight interactions
